✦ About the project

Built for real student life.

We created StudyFlow as a beginner-friendly front-end website project that helps students organize academic tasks and discover learning resources.

Our idea

Students often juggle assignments, deadlines, classes, and personal goals. A clear dashboard can reduce confusion and help make small improvements every day.

Our website uses responsive HTML, CSS, and JavaScript. It includes navigation, form validation, local demo authentication, task management, filtering, and theme preferences.
