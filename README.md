# StudyFlow — Student Productivity Website

A responsive multi-page educational front-end website for Astana IT University final project.

## Run locally

Open `index.html` in a modern browser, or run `python3 -m http.server 8000` from inside this folder and visit http://localhost:8000/.

## Pages
Home, Courses, Planner, About, Contact, Sign Up, Log In and Profile (8 total).

## Features
- Responsive layouts and mobile navigation.
- Persistent light/dark theme (localStorage).
- Local-only registration and login simulation.
- Validated signup, login and contact forms with inline errors.
- Searchable and filterable course catalog with saved filters.
- Profile and per-user persistent task planner with progress indicator.
- Keyboard navigation, descriptive images and accessible labels.

## Safety notice
This is **only** a classroom front-end demonstration: passwords are stored in localStorage as required by the assignment. Never use real passwords or sensitive information. There is no backend, real access control or email delivery. The catalog is static sample data, not actual hosted lessons.

## Deployment
Create a GitHub repository, upload this folder's *contents* to its root, then enable GitHub Pages (Settings → Pages → Deploy from a branch → main / root). Copy the real repository and live URLs into the supplied Links.txt before submitting. Alternatively deploy via Netlify.
